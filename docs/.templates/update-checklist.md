---

### 📋 内容更新

- [ ] **新命令** — 插件新增的 Slash 命令是否已添加到「命令参考」表格
- [ ] **已移除命令** — 废弃的命令是否已从「命令参考」中删除或标注为已弃用
- [ ] **命令参数变更** — 现有命令的参数（必需/可选/格式）是否有变化
- [ ] **安装方式变更** — 安装命令或前置条件是否有变化
- [ ] **默认行为变更** — 插件的默认行为是否发生变化，影响场景描述

### 🎬 媒体素材

- [ ] **截图** — 现有截图是否仍然准确反映当前界面
  - 如否，运行 `bash scripts/screenshot.sh [插件名]` 更新截图
- [ ] **录屏 GIF** — 现有录屏的交互流程是否仍然可复现
  - 如否，运行 `bash scripts/record.sh [插件名]` 更新录屏
- [ ] **新增媒体** — 是否需要为新增功能添加截图/录屏

### 📝 文案更新

- [ ] **概述** — 核心能力列表是否需要增删
- [ ] **使用场景** — 是否有新的典型场景需要添加
- [ ] **实战案例** — 现有案例的命令是否仍然可执行
- [ ] **常见问题** — 新版本是否引入了新的常见问题
- [ ] **相关插件** — 与其他插件的协作关系是否有变化

### ✅ 质量确认

- [ ] 所有命令示例已实际测试，可成功执行
- [ ] 内部链接（相关插件引用）仍然有效
- [ ] 「最后更新」日期已更新
- [ ] `media-inventory.md` 已同步更新

---

## 完成标记

- [ ] 检查完成，文档已与插件 v{y.y.y} 同步

---

> 💡 **提示**：如果只是小版本更新（补丁版本），通常只需检查命令变更和截图准确性。
> 大版本更新（主版本号变化）建议完整走一遍清单。
