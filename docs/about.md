# 关于本站

## Night Market 是什么？

Night Market 是 Claude Code 的插件生态系统，包含 23 个覆盖全开发周期的官方和社区插件。这些插件扩展了 Claude Code 的能力边界，从项目构思到代码审查，从安全审计到多 Agent 编排，为开发者提供全方位的 AI 辅助支持。

## 关于本站

本站是 Night Market 全部插件的中文使用说明书，旨在帮助中文用户：

- 🔍 **快速查找** — 通过分类索引或关键词搜索，找到需要的插件
- 📖 **深入了解** — 每个插件都包含详细的命令参考、使用场景和实战案例
- 🎯 **场景驱动** — 按实际需求场景查找推荐的插件组合
- 🎬 **所见即所得** — 大量截图和终端录屏，直观展示操作流程

## 技术栈

本站使用以下技术构建：

| 技术 | 用途 |
|------|------|
| [VitePress](https://vitepress.dev/) | 静态站点生成 |
| [GitHub Pages](https://pages.github.com/) | 站点托管 |
| [GitHub Actions](https://github.com/features/actions) | CI/CD 自动部署 |
| phantom 插件 | 终端截图 |
| scry 插件 | 终端录屏 |
